Catálogo de Endpoints REST UTP

Spring Boot 3 + OpenAPI 3.0

POST /api/auth/login 200 OK

Autenticación de operadores y administradores TI (JWT/Token).

GET /api/incidents/stats 200 OK

Métricas consolidadas: total, activos, inactivos, severidad y categorías.

GET /api/incidents/stats/by-category 200 OK

Total de incidencias agrupadas por categoría (Redes, Hardware, etc.).

POST /api/incidents 200 OK

Creación de ticket con título, descripción, severidad, categoría y ubicación.

PATCH /api/incidents/{id}/status 200 OK

Actualiza estado (Active / Inactive) y notas de rechazo o resolución.

DELETE /api/incidents/{id} 204 No Content

Elimina permanentemente un incidente en la base de datos.
